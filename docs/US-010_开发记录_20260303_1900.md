## 功能概述

实现批量生成图片时支持顺序/并行生成模式选择，失败后可选择继续或停止，显示总体进度和当前处理项。

### 3. 失败处理弹框

**文件**: `src/App.tsx`

当批量生成过程中发生失败时，弹出处理弹框让用户选择：

- 停止生成
- 继续生成

```tsx
<Modal
  title="生成失败"
  open={failModalVisible}
  footer={[
    <Button key="stop" onClick={handleFailStrategyStop}>
      停止生成
    </Button>,
    <Button key="continue" type="primary" onClick={handleFailStrategyContinue}>
      继续生成
    </Button>,
  ]}
  closable={false}
>
  <Alert
    message="某个场景生成失败"
    description={`场景 ${failedSceneIndex + 1} 生成失败，您可以选择继续生成剩余场景或停止。`}
    type="warning"
    showIcon
  />
</Modal>
```

### 5. 绑定模式切换功能

**文件**: `src/App.tsx`

在批量拆分结果标题旁添加了绑定模式切换：

- 逐个绑定：每个场景单独绑定角色
- 全局绑定：所有场景共享角色绑定

```tsx
<Radio.Group
  value={bindMode}
  onChange={e => {
    setBindMode(e.target.value);
    if (e.target.value === 'global') {
      const allChars = new Set<string>();
      batchSplitResult.segments.forEach((seg: any) => {
        (seg.characters || []).forEach((c: any) =>
          allChars.add(typeof c === 'string' ? c : c.name)
        );
      });
      setGlobalCharacterList(Array.from(allChars));
    }
  }}
  size="small"
  style={{ marginLeft: 12 }}
>
  <Radio.Button value="individual">逐个绑定</Radio.Button>
  <Radio.Button value="global">全局绑定</Radio.Button>
</Radio.Group>
```
