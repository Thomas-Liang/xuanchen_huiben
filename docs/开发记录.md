## Sprint 0: 项目初始化

### 2026-02-25

#### 完成的工作

1. **Tauri + React 项目初始化**
   - 使用 `npm create tauri-app` 创建项目
   - 技术栈: React 18 + TypeScript + Vite + Tauri 2.x
   - 项目名称: xuanchen-huiben

2. **开发环境配置**
   - 安装 ESLint、Prettier
   - 安装 Zustand (状态管理)
   - 安装 Axios (HTTP请求)
   - 安装 Ant Design (UI组件)
   - 配置 `.eslintrc.json` 和 `.prettierrc`

3. **项目结构搭建**

   ```
   src/
   ├── components/     # React组件
   ├── hooks/          # 自定义Hooks
   ├── types/          # TypeScript类型定义
   ├── services/       # API服务
   ├── store/          # Zustand状态管理
   └── utils/          # 工具函数

   src-tauri/
   └── src/
       └── commands/   # Tauri命令
   ```

4. **核心类型定义** (`src/types/index.ts`)
   - `PromptSegment` - 提示词分段
   - `ParsedPrompt` - 解析结果
   - `CharacterRef` - 角色引用
   - `CharacterBinding` - 角色绑定
   - `ImageGenerationParams` - 出图参数
   - `APIConfig` - API配置

5. **状态管理** (`src/store/index.ts`)
   - 使用 Zustand + persist 中间件
   - 管理 API配置、解析结果、角色绑定、出图参数

6. **Rust后端命令** (`src-tauri/src/lib.rs`)
   - `parse_prompt` - 提示词解析（提取@角色、分段）
   - 支持中文字符识别

7. **前端界面** (`src/App.tsx`)
   - 提示词输入框
   - 解析结果显示（角色列表、分段结果）
   - Ant Design UI组件

8. **配置文件更新**
   - `tauri.conf.json` - 应用名称、大小、窗口配置
   - `package.json` - 项目名称、脚本配置
   - `Cargo.toml` - Rust依赖

#### 遇到的问题

1. **Rust编译链接问题**
   - MSVC链接器环境配置复杂
   - 当前环境: VS Build Tools 14.44 + Windows SDK 10.0.26100
   - 错误: `LINK : fatal error LNK1104: 无法打开文件"msvcrt.lib"`
   - 解决方案: 配置正确的环境变量后成功编译

### 2026-03-06

#### US-09: 历史记录时间线浏览与筛选增强

**完成的工作**:

1. **后端日期格式标准化**
   - 修改 `src-tauri/src/storage/mod.rs` 中的日期格式为 RFC3339。
   - 在 `get_history` 中增加对旧格式 (`%Y-%m-%d %H:%M:%S`) 的解析回退，确保数据兼容性。

2. **补全 Axum HTTP API** (`src-tauri/src/api.rs`)
   - 实现了历史记录相关的 HTTP 接口：`api_get_history_handler`, `api_add_history_handler`, `api_delete_history_handler`, `api_clear_history_handler`。
   - 解决了 Web 环境下无法管理历史记录的问题。

3. **前端搜索功能优化** (`src/components/history/HistoryList.tsx`)
   - 引入 500ms 搜索防抖 (Debounce)，大幅减少不必要的后端请求。
   - 统一了历史记录搜索的触发流程。

4. **UI/UX 增强**
   - 使用 **Framer Motion** 为历史分组添加了平滑的入场和离场动画。
   - 实现了 "按日期分组" 的逻辑，将记录按“今天”、“昨天”或具体日期进行聚合展示。
   - 增加了 "重置筛选" 功能。

5. **参数快速应用 (US-10 部分功能)**
   - 在 `App.tsx` 中实现 `handleApplyHistoryParams`。
   - 历史记录项中添加 "使用参数" 按钮，一键将历史生成参数回填至工作台，支持快速复用。

**修改的文件**:

- `src-tauri/src/storage/mod.rs` - 日期格式与回退逻辑
- `src-tauri/src/api.rs` - 补全 HTTP API
- `src/components/history/HistoryList.tsx` - 搜索防抖、动画、UI 布局
- `src/App.tsx` - 集成参数回填逻辑
