## 技术细节

### 数据结构

```rust
struct ShareData {
    version: String,
    data_type: String,
    created_at: String,
    expires_at: Option<String>,
    password_protected: bool,
    metadata: ShareMetadata,
    images: Vec<String>,
}

struct ShareRecord {
    id: String,
    data: ShareData,
    password: Option<String>,
    expires_at: Option<String>,
    created_at: String,
}
```

### 局域网分享

- 使用 `get_local_ip_address()` 获取电脑局域网 IP
- API 服务器监听 `0.0.0.0:8888`
- 分享链接格式: `http://[局域网IP]:8888/share/[share_id]`
- 二维码使用第三方服务 `api.qrserver.com`

### 图片处理

- 本地文件自动转换为 Base64
- 支持已有 base64 数据直接使用

## 问题与解决

1. **Rust format! 参数不匹配** - HTML 模板中使用 `{}` 占位符，修复参数顺序
2. **密码保护逻辑** - 分离 content_start 和 password_script 到不同占位符
3. **API 路由未注册** - 添加分享相关 API 路由到 api.rs
4. **历史记录分享失败** - 本地图片路径无法分享，添加 base64 转换
5. **二维码无法扫描** - 分享链接使用 tauri.localhost，改为局域网 IP
6. **手机无法访问** - API 只监听 127.0.0.1，改为 0.0.0.0
