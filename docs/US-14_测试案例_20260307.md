# US-14 测试案例

**功能**: 实现提示词历史自动保存  
**日期**: 2026-03-07

---

## 测试环境

- 平台: Windows 桌面应用
- 版本: Tauri 2.x + React 19

---

## 测试用例

### T14.1: 自动保存提示词

| 编号    | 测试步骤                     | 预期结果                               |
| ------- | ---------------------------- | -------------------------------------- |
| T14.1.1 | 输入提示词并点击“开始解析”   | 提示词被自动写入历史                   |
| T14.1.2 | 输入提示词并点击“拆分场景”   | 批量模式下同样自动写入历史             |
| T14.1.3 | 输入空提示词并触发操作       | 不保存空记录                           |

### T14.2: 下拉展示与一键复用

| 编号    | 测试步骤                           | 预期结果                                   |
| ------- | ---------------------------------- | ------------------------------------------ |
| T14.2.1 | 查看输入框上方“提示词历史”下拉     | 展示最近历史提示词                         |
| T14.2.2 | 点击任意历史项                     | 主输入框自动回填该提示词                   |
| T14.2.3 | 在下拉框输入关键字搜索             | 可筛选匹配的历史项                         |

### T14.3: 去重、排序、容量

| 编号    | 测试步骤                                   | 预期结果                                       |
| ------- | ------------------------------------------ | ---------------------------------------------- |
| T14.3.1 | 连续多次保存同一提示词                     | 历史中仅保留一条，`use_count` 累加             |
| T14.3.2 | 先保存 A，再保存 B，再重复保存 A           | A 排到最前（按最近使用时间倒序）               |
| T14.3.3 | 构造超过 50 条不同提示词                   | 最终最多保留 50 条                              |

### T14.4: 兼容性验证

| 编号    | 测试步骤                                  | 预期结果                               |
| ------- | ----------------------------------------- | -------------------------------------- |
| T14.4.1 | 使用旧版数据库启动应用                    | 正常启动，无解析异常                   |
| T14.4.2 | 打开提示词历史下拉                        | 可正常显示（为空或已有数据）           |

### T14.5: 历史管理操作

| 编号    | 测试步骤                         | 预期结果                               |
| ------- | -------------------------------- | -------------------------------------- |
| T14.5.1 | 点击“删首条”                     | 删除当前筛选结果的首条历史，列表刷新   |
| T14.5.2 | 点击“清空”并确认                | 全部历史清空成功                       |
| T14.5.3 | 输入框为空时按 Enter             | 自动回填最近一条历史提示词             |
| T14.5.4 | 输入框非空时按 Enter             | 不触发历史回填（保持原输入行为）       |

### T14.6: 生图异常提示与自动降级

| 编号    | 测试步骤                                         | 预期结果                                                   |
| ------- | ------------------------------------------------ | ---------------------------------------------------------- |
| T14.6.1 | Banana Pro 携带较大参考图生成                    | 网关异常时触发自动降级重试，不直接中断                    |
| T14.6.2 | 自动降级成功后查看结果区                         | 显示 warning 提示（如“已自动处理请求异常”）               |
| T14.6.3 | 参考图超限被跳过                                 | 显示“参考图被自动跳过”类提示，用户可理解结果差异          |
| T14.6.4 | 人为触发常见网关错误（400/413/JSON 截断）       | 前端显示统一易懂错误文案，不出现难懂的原始报错堆叠        |

### T14.7: 历史记录导出

| 编号    | 测试步骤                                           | 预期结果                                                     |
| ------- | -------------------------------------------------- | ------------------------------------------------------------ |
| T14.7.1 | 打开历史弹窗并设置筛选条件                         | 列表显示筛选后的历史记录                                     |
| T14.7.2 | 点击底部“导出JSON”并保存                           | 成功导出 JSON 文件，内容为当前筛选条件下全部匹配记录        |
| T14.7.3 | 点击底部“导出MD”并保存                             | 成功导出 Markdown 文件，内容可读且包含关键字段              |
| T14.7.4 | 筛选无数据后执行导出                               | 提示“没有可导出的历史记录”，不生成空文件                    |
