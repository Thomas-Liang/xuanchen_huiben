# US-009 批量生成并发数配置功能 - 开发记录

**User Story**: US-009
**标题**: 批量生成并发数可配置
**开发日期**: 2026-03-01
**状态**: 开发完成，待测试验证

---

## 功能概述

实现批量生成图片时可配置并发数（1-5），支持使用 seedream 或 banana 2 模型进行多并发同时生图。

## 技术细节

### 并发实现逻辑

使用 JavaScript 的 `Promise.all` 实现并发控制：

```typescript
const concurrencyLimit = concurrency;
const tasks = [...batchSplitResult.segments];

for (let i = 0; i < tasks.length; i += concurrencyLimit) {
  const chunk = tasks.slice(i, i + concurrencyLimit);
  await Promise.all(chunk.map((task, chunkIdx) => runTask(task, i + chunkIdx)));
}
```

### 配置持久化

并发数配置通过 `saveGenerationConfig` / `loadGenerationConfig` 与其他生成参数一起保存和加载。
