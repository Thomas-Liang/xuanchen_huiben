# US-009 批量生成并发数配置功能 - 测试案例

**User Story**: US-009
**标题**: 批量生成并发数可配置
**测试日期**: 2026-03-01
**状态**: 待测试

---

## 功能概述

实现批量生成图片时可配置并发数（1-5），支持使用 seedream 或 banana 2 模型进行多并发同时生图。

本文档涵盖 US-009 批量生成并发数配置功能的所有测试案例。

---

## 测试环境

- **前端**: React + TypeScript + Ant Design
- **后端**: Rust + Tauri
- **测试工具**: 手动测试

---

## 测试案例

### TC-001: 并发数默认值验证

**前置条件**: 首次使用应用

**测试步骤**:

1. 打开应用
2. 进入生成参数设置区域
3. 查看并发数输入框的默认值

**预期结果**: 并发数默认值为 2

---

### TC-02: 并发数设置范围验证

**前置条件**: 应用正常运行

**测试步骤**:

1. 在并发数输入框中输入 1
2. 尝试输入 0
3. 尝试输入 6
4. 尝试输入 5

**预期结果**:

- 输入 1: 成功设置
- 输入 0: 自动重置为 2 或无法输入
- 输入 6: 无法输入（最大值为 5）
- 输入 5: 成功设置

---

### TC-03: 并发数保存验证

**前置条件**: 应用正常运行

**测试步骤**:

1. 设置并发数为 3
2. 点击"保存为默认配置"按钮
3. 刷新页面
4. 查看并发数

**预期结果**: 刷新后并发数仍为 3

---

### TC-04: Seedream 模型并发生图

**前置条件**:

- Seedream API 已配置
- 有批量拆分结果

**测试步骤**:

1. 选择 Seedream 模型
2. 设置并发数为 3
3. 输入批量提示词
4. 点击"拆分场景"
5. 点击"全部生图"

**预期结果**: 3 张图片同时生成

---

### TC-05: Banana 2 模型并发生图

**前置条件**:

- Banana 2 API 已配置
- 有批量拆分结果

**测试步骤**:

1. 选择 Banana 2 模型
2. 设置并发数为 4
3. 输入批量提示词
4. 点击"拆分场景"
5. 点击"全部生图"

**预期结果**: 4 张图片同时生成

---

### TC-06: 不同并发数性能对比

**前置条件**:

- 有 6 个场景的批量拆分结果

**测试步骤**:

1. 设置并发数为 1，记录生成时间 T1
2. 设置并发数为 2，记录生成时间 T2
3. 设置并发数为 3，记录生成时间 T3

**预期结果**: T1 > T2 >= T3（并发数越大，生成时间越短）

---

### TC-07: 并发数超出场景数量

**前置条件**:

- 只有 2 个场景的批量拆分结果

**测试步骤**:

1. 设置并发数为 5
2. 点击"全部生图"

**预期结果**: 2 张图片同时生成，不报错

---

### TC-08: 批量拆分结果绑定角色图

**前置条件**:

- 应用正常运行

**测试步骤**:

1. 输入包含角色的批量提示词（如 `场景1: 公园里@小明 在跑步|场景2: 街道@女孩 在行走`）
2. 点击"拆分场景"
3. 点击第一个场景的展开箭头
4. 查看"主角色与参考图绑定"区域
5. 点击"绑定参考图"按钮
6. 选择一张参考图并确认绑定

**预期结果**:

- 拆分结果显示2个场景
- 展开后显示角色列表
- 绑定成功后显示已绑定状态和参考图头像

---

### TC-09: 批量拆分结果解绑角色图

**前置条件**:

- 已完成角色绑定的批量拆分结果

**测试步骤**:

1. 在已绑定角色的场景中
2. 点击"解绑"按钮

**预期结果**: 角色解绑成功，状态变为"未绑定"

---

### TC-10: 批量生成使用已绑定的角色参考图

**前置条件**:

- 已绑定角色的批量拆分结果

**测试步骤**:

2. 点击"全部生图"

**预期结果**: 生成的图片中使用了绑定的人物参考图

### TC-11: 批量生成设置弹框

**前置条件**:

- 有批量拆分结果

**测试步骤**:

1. 点击"设置"按钮
2. 弹出批量生成设置弹框
3. 查看弹框中的参数选项

**预期结果**:

- 显示模型选择 (Seedream 4.5 / Banana 2)
- 显示并发数输入框 (1-5)
- Seedream 模型显示：图片尺寸、图片质量、组图功能、返回格式、水印
- Banana 2 模型显示：图片比例、分辨率
