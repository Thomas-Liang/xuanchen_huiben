## 技术方案与实现

### 后端 (Rust)

1. **Folder 数据模型**
   - `id`: 文件夹 ID
   - `name`: 文件夹名称
   - `parent_id`: 父文件夹 ID（`null` 表示根层）
   - `created_at`: 创建时间

2. **API 设计与实现**
   - `create_folder(name, parent_id)`：创建文件夹
   - `rename_folder(id, new_name)`：重命名文件夹
   - `delete_folder(id)`：删除文件夹（含子文件夹清理）
   - `get_folders(parent_id)`：获取指定层级文件夹
   - `get_folder_tree()`：获取完整树
   - `move_image_to_folder(character_name, folder_id)`：移动图片
   - `get_reference_images(query)`：支持 `folder_id` 过滤

3. **关键补丁**
   - `move_image_to_folder` 增加持久化：移动后写回 `character_bindings.json`，避免重启丢失。
   - `create_folder` 新增同级重名校验（忽略大小写、去空格）。
   - `rename_folder` 新增同级重名校验（排除自身，忽略大小写、去空格）。

4. **数据持久化**
   - 文件夹配置：`config/folders.json`
   - 绑定配置：`config/character_bindings.json`
   - 启动时自动加载。

### 前端 (React)

1. **ReferenceLibrary 组件化接入**
   - 将参考图管理能力统一收敛到 `ReferenceLibrary` 组件。
   - 替换主页面旧版临时弹窗实现，避免逻辑分叉。

2. **文件夹树与视图语义**
   - 树节点区分：
     - `全部图片`：展示全量
     - `未分类(根目录)`：仅展示 `folder_id == null` 的图片
     - 用户自定义文件夹：按 ID 过滤
   - 节点按钮支持：新建子文件夹 / 重命名 / 删除。

3. **上传与移动**
   - 上传弹窗支持 `保存至文件夹`（`TreeSelect`）。
   - 若当前选中目录，上传后自动归档到当前目录。
   - 移动后根据当前视图刷新正确数据源（全部/根目录/具体文件夹）。

4. **冲突校验与反馈**
   - 前端在创建/重命名前做同级重名预检，立即 `message.error`。
   - 后端同样校验，防止绕过前端调用。
   - 异常文案透传到 UI 便于定位。

5. **布局优化**
   - 弹窗宽度改为自适应（大屏上限 + 小屏比例）。
   - 顶部筛选与操作区改为单行排列并拉开间距。
   - 顶部工具区增加响应式规则：大屏单行，小屏自动换行并保持可点击区域。
   - 左侧文件夹区固定宽度可滚动，右侧卡片区响应式。
   - 图片卡片支持点击预览完整大图（不影响卡片操作按钮）。
