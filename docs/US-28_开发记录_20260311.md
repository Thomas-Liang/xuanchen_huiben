# US-28 开发记录 - 桌面通知

> 日期: 2026-03-12

## 功能概述

在图片生成完成或失败时发送系统桌面通知。

## 验收标准

- [x] 生成完成时发送系统通知
- [x] 生成失败时发送系统通知（含失败原因）
- [x] 可在设置中开关通知
- [ ] 支持通知点击跳转查看结果（可选）

## 开发内容

### 前端 (src/)

1. **App.tsx** - 修改
   - 导入 `invoke` from `@tauri-apps/api/core`
   - 导入 `@tauri-apps/plugin-notification`
   - 在图片生成完成后调用通知 API

### 后端 (src-tauri/)

1. **Cargo.toml** - 新增依赖
   - `tauri-plugin-notification = "2"`

2. **lib.rs** - 修改
   - 添加 notification 插件
   - 新增 `send_notification` 命令
   - 新增 `is_notification_enabled` 命令

3. **storage/mod.rs** - 修改
   - UiConfig 新增 `notification_enabled` 字段（默认 true）

4. **capabilities/default.json** - 修改
   - 添加 notification 权限

## 技术细节

### 通知流程

1. 用户生成图片完成后
2. 检查通知设置是否开启 (`is_notification_enabled`)
3. 检查系统通知权限 (`isPermissionGranted`)
4. 请求权限（如需要）(`requestPermission`)
5. 发送系统通知

### 通知内容

- 生成成功: "图片生成完成 - 成功生成 X 张图片"
- 生成失败: "图片生成失败 - [错误信息]"

## 问题与解决

1. **缺少 notification 插件** - 添加 tauri-plugin-notification 依赖
2. **缺少前端权限** - 添加 @tauri-apps/plugin-notification npm 包
3. **缺少 capability 权限** - 在 default.json 中添加 notification 权限
4. **通知不显示** - 添加权限请求逻辑
