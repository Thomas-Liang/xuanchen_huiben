# US-28 开发记录（2026-03-11）

## 一、用户故事

作为用户，我希望查看生成数据的可视化报表和统计分析，以便了解使用情况和优化方向。

## 二、验收标准

- [x] 生成统计报表（成功率、数量趋势）
- [x] API调用分析（调用次数、响应时间、失败率）
- [x] 模板使用统计（使用次数、收藏偏好）
- [x] 数据持久化存储

## 三、关键实现点

### 1) 图表库引入

使用 **Recharts** 作为图表库：

- 折线图 - 生成数量趋势
- 饼图 - 模型使用分布
- 柱状图 - API响应时间
- 统计卡片 - 关键指标

### 2) 数据模型

新增统计相关数据结构：

- `GenerationStats` - 生成统计数据
- `ApiCallLog` - API调用日志
- `TemplateUsage` - 模板使用记录

### 3) 后端 API

- `get_generation_stats` - 获取生成统计
- `get_api_call_logs` - 获取API调用日志
- `get_template_usage` - 获取模板使用统计

### 4) 前端界面

- 首页添加统计概览区域
- 新增统计页面（可从边栏进入）
- 统计图表展示
