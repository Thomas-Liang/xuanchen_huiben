# US-28 开发记录（2026-03-11）

## 一、用户故事

作为用户，我希望查看生成数据的可视化报表和统计分析，以便了解使用情况和优化方向。

## 二、验收标准

- [x] 生成统计报表（成功率、数量趋势）
- [x] API调用分析（调用次数、响应时间、失败率）
- [x] 模板使用统计（使用次数、收藏偏好）
- [x] 数据持久化存储

## 三、关键实现点

### 1) 图表库引入

使用 **Recharts** 作为图表库：

- 折线图 - 生成数量趋势
- 饼图 - 模型使用分布
- 柱状图 - API响应时间、模板使用排行

### 2) 数据模型

新增统计相关数据结构（storage/mod.rs）：

- `GenerationStats` - 生成统计数据
- `ModelUsage` - 模型使用统计
- `DailyStats` - 每日统计
- `ApiStats` - API调用统计
- `ApiCallLog` - API调用日志
- `TemplateStats` - 模板使用统计
- `TemplateUsage` - 模板使用记录

### 3) 后端 API

- `get_generation_stats(days)` - 获取生成统计
- `get_api_stats(limit)` - 获取API调用统计
- `get_template_stats()` - 获取模板使用统计

### 4) 前端界面

- 新增统计页面组件（src/components/stats/StatsPage.tsx）
- 集成到应用边栏（Toolbar）
- 三个 Tab 页：生成统计、API调用、模板统计

## 四、涉及文件

### Rust 后端

- `src-tauri/src/storage/mod.rs` - 统计数据模型和函数
- `src-tauri/src/lib.rs` - 统计命令注册

### TypeScript 前端

- `src/api.ts` - 统计 API 接口
- `src/components/stats/StatsPage.tsx` - 统计页面组件
- `src/components/stats/index.ts` - 组件导出
- `src/components/Toolbar.tsx` - 添加统计导航项
- `src/App.tsx` - 集成统计页面

## 五、使用方式

1. 点击侧边栏"统计"按钮
2. 查看三个 Tab 页的数据：
   - 生成统计：总生成数、成功率、每日趋势、模型分布
   - API调用：调用次数、响应时间、各模型统计
   - 模板统计：模板使用次数、收藏数排行
