## 功能概述

图标工具栏是应用左侧的导航侧边栏，提供工作台、参考图库、历史记录、模板、账号、设置等功能的快速入口。

### UI 设计规格

```
┌────┬──────────────────────────────────────────────────────┐
│ 🏠 │                                                      │
│工作台│                     主内容区域                      │
├────┤                                                      │
│ 🖼️ │                                                      │
│图库 │                                                      │
├────┤                                                      │
│ 📜 │                                                      │
│历史 │                                                      │
├────┤                                                      │
│ 📝 │                                                      │
│模板 │                                                      │
├────┤                                                      │
│ 🤖 │                                                      │
│账号 │                                                      │
├────┤                                                      │
│ ⚙️ │                                                      │
│设置 │                                                      │
└────┴──────────────────────────────────────────────────────┘
  48px → 120px (hover)
```
