# 使用帮助

## 1. 参考图管理入口

1. 打开应用主界面。
2. 点击工具栏中的“参考图管理”。
3. 进入后可在同一窗口完成文件夹管理、上传、移动、标签维护和预览。

## 2. 文件夹管理

- **新建文件夹**：点击顶部“新建文件夹”。
- **新建子文件夹**：在左侧树对应文件夹行点击“+”。
- **重命名**：点击文件夹行的编辑图标。
- **删除**：点击文件夹行的删除图标并确认。
- **同名限制**：同级目录下不允许重名（忽略大小写和首尾空格）。

## 3. 图片上传与归档

1. 点击“上传图片”。
2. 填写“角色/参考图名称”并选择图片类型。
3. 在“保存至文件夹”中选择目标目录（留空则为未分类根目录）。
4. 点击“确认上传”。

## 4. 图片移动

1. 在图片卡片下方点击“移动”。
2. 选择目标文件夹。
3. 列表会自动刷新到当前视图。

## 5. 筛选与视图

- 顶部支持关键词搜索、类型筛选、标签筛选。
- 左侧树视图：
  - **全部图片**：显示所有图片
  - **未分类(根目录)**：仅显示未归档图片
  - **自定义文件夹**：显示该目录下图片

## 6. 图片预览

- 点击卡片封面图即可查看大图预览。
- 预览窗口可查看完整图片细节。

## 7. 常见问题

### Q1: 新建/重命名提示同名冲突怎么办？

A: 请更换名称，或检查同一父目录下是否已存在同名文件夹。

### Q2: 上传后图片没在当前目录显示？

A: 先确认上传时“保存至文件夹”选择是否正确，再检查左侧当前是否处于“全部图片”或其他目录筛选。

### Q3: 移动后重启应用目录丢失？

A: 当前版本会自动持久化移动结果；若异常，请重启后再次检查并提供报错信息。
