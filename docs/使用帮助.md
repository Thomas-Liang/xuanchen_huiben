# 使用帮助

## 1. 参考图管理入口

1. 打开应用主界面。
2. 点击工具栏中的“参考图管理”。
3. 进入后可在同一窗口完成文件夹管理、上传、移动、标签维护和预览。

## 2. 文件夹管理

- **新建文件夹**：点击顶部“新建文件夹”。
- **新建子文件夹**：在左侧树对应文件夹行点击“+”。
- **重命名**：点击文件夹行的编辑图标。
- **删除**：点击文件夹行的删除图标并确认。
- **同名限制**：同级目录下不允许重名（忽略大小写和首尾空格）。

## 3. 图片上传与归档

1. 点击“上传图片”。
2. 填写“角色/参考图名称”并选择图片类型。
3. 在“保存至文件夹”中选择目标目录（留空则为未分类根目录）。
4. 点击“确认上传”。

## 4. 图片移动

1. 在图片卡片下方点击“移动”。
2. 选择目标文件夹。
3. 列表会自动刷新到当前视图。

## 5. 筛选与视图

- 顶部支持关键词搜索、类型筛选、标签筛选。
- 左侧树视图：
  - **全部图片**：显示所有图片
  - **未分类(根目录)**：仅显示未归档图片
  - **自定义文件夹**：显示该目录下图片

## 6. 图片预览

- 点击卡片封面图即可查看大图预览。
- 预览窗口可查看完整图片细节。

## 7. 批量操作

进入"多选模式"后可进行批量操作：

1. **进入多选模式**：点击顶部"多选模式"按钮
2. **选择图片**：点击图片卡片左上角的复选框选择要操作的图片
3. **批量移动**：选择图片后点击"批量移动"，选择目标文件夹
4. **批量标签**：选择图片后点击"批量标签"，输入标签（多个用逗号分隔）
5. **批量删除**：选择图片后点击"批量删除"，确认后批量删除
6. **全选**：点击"全选"快速选中所有图片
7. **取消多选**：点击"取消多选"退出多选模式

## 8. 常见问题

### Q1: 新建/重命名提示同名冲突怎么办？

A: 请更换名称，或检查同一父目录下是否已存在同名文件夹。

### Q2: 上传后图片没在当前目录显示？

A: 先确认上传时“保存至文件夹”选择是否正确，再检查左侧当前是否处于“全部图片”或其他目录筛选。

### Q3: 移动后重启应用目录丢失？

A: 当前版本会自动持久化移动结果；若异常，请重启后再次检查并提供报错信息。

### Q4: 批量操作在哪里？

A: 在参考图管理界面，点击"多选模式"按钮进入批量操作模式。

## 9. 模板库（左侧导航“模板”）

模板库用于沉淀高频提示词结构，减少重复输入，提升生图效率。

1. 打开左侧导航的“模板”。
2. 选择任一模板点击“使用”，内容会自动填充到主输入框。
3. 将模板中的 `{地点}`、`{人物}`、`{动作}` 等变量替换为实际内容。
4. 点击开始生成即可。

当前版本内置 3 条可直接使用的模板：

- 儿童绘本场景模板
- 国风插画模板
- 电影感写实模板

### Q5: 模板有什么作用？

A: 模板适合“同结构、多主题”的场景。你只需替换少量变量，就能快速得到风格稳定的提示词，并可在历史记录中持续复用与优化。

## 10. 提示词历史（US-14）

为减少重复输入，系统会自动保存你实际使用过的提示词。

1. 在主输入区上方找到“提示词历史（可一键复用）”下拉框。
2. 输入并执行“开始解析”或“拆分场景”后，提示词会自动进入历史。
3. 下拉中可直接点击历史项，一键回填到输入框。
4. 支持搜索历史内容快速定位。
5. 可使用“删首条”快速删除当前筛选首项，或“清空”一次清空全部历史。
6. 当输入框为空时，按 Enter 可快速回填最近一条历史。

规则说明：

- 自动去重：相同提示词不会重复新增。
- 最近优先：最近使用的提示词排在前面。
- 容量限制：最多保留 50 条历史记录。

### Q6: 为什么历史里看不到刚输入的提示词？

A: 需要触发一次解析或拆分动作才会自动保存；空提示词不会被记录。

### Q7: 如何删除提示词历史？

A: 在提示词历史右侧可点击“删首条”删除当前筛选首项；点击“清空”可清空全部历史（有二次确认）。

### Q8: 生成时提示“已自动处理请求异常”是什么意思？

A: 这表示系统检测到网关拒绝/截断了参考图请求，已自动降级为更稳妥的请求方式并重试成功。通常可以直接继续使用；若频繁出现，建议减少参考图数量或压缩图片大小。

### Q9: 历史记录如何导出？

A: 打开“生成历史记录”弹窗，在底部左侧点击“导出JSON”或“导出MD”即可导出。导出内容会遵循当前筛选条件，并包含全部匹配记录（不只是当前页）。

## 11. 首页今日概览看板

主界面顶部提供“今日概览”看板，便于快速掌握当天状态：

1. 第一张卡显示“日期 + 星期 + 当前时间（HH:mm:ss）”，时间会实时更新。
2. 其余卡片分别显示“生成总数 / 成功率 / 失败数 / 最近失败”。
3. 看板为单排卡片布局，不会占用过高空间（当前版本不显示底部进度条）。
4. “最近失败”内容过长会自动省略，鼠标悬浮可查看完整文本。

### Q10: 提示词长度颜色代表什么？

A: 输入框标题右侧的 `（当前长度 / 最大长度）` 会按占比变色：低占比为紫色、接近上限变橙色、接近/达到上限变红色；悬浮可查看提示说明。

## 12. 任务队列中心（US-22 V1）

为便于控制多场景生成，当前版本已支持基础任务队列：

1. 在解析结果区域点击“加入队列”，将当前单图/批量任务放入队列。
2. 点击“任务队列”可查看状态：`pending / running / paused / completed / failed / cancelled`。
3. 可对单任务执行“暂停 / 继续 / 取消 / 重试”。
4. 可点击“清理已结束”快速移除已完成/失败/取消的任务。
5. 队列元数据会本地保存，应用重启后可恢复（运行中任务会转为暂停）。

测试建议：

- 在“生成设置”中开启“队列测试模式”，可配置模拟延迟和失败场景序号。
- 测试模式不调用真实生图 API，不写入历史，适合验证暂停/继续/重试流程。

### Q11: 为什么点了暂停，没有立刻停？

A: 当前版本是“分段级暂停”。若当前分段请求已发出，会在该分段完成后暂停，不再发起下一条请求。

### Q12: 为什么任务加入后很快就完成了？

A: 常见原因是分段数量太少（例如只有 1 条）。建议使用 3-5 个场景进行队列控制测试，暂停效果更明显。

## 13. 统计页面（US-28）

点击左侧导航"统计"可进入数据分析页面，查看生成数据可视化报表。

### 13.1 生成统计

- **总生成数**：历史累计生成图片总数
- **成功率**：成功次数 / 总次数的百分比
- **每日生成趋势**：折线图展示近30天每天的生成数量、成功数、失败数
- **模型使用分布**：饼图展示各模型的使用占比

### 13.2 API调用

- **总调用次数**：API 请求总次数
- **平均响应时间**：API 平均响应耗时（毫秒）
- **各模型API统计**：柱状图展示各模型的调用次数和平均响应时间

### 13.3 模板统计

- **模板总数**：已创建的模板数量
- **收藏数**：已收藏的模板数量
- **模板使用排行**：柱状图展示各模板的使用次数排名

## 14. API配置说明

点击右上角"API配置"按钮进入配置页面。

### 14.1 Seedream API

- **Base URL**: API 服务地址，如 `https://api.zhongzhuan.chat`
- **API Key**: 用于身份验证的密钥
- **特点**: 支持 1K/2K/4K 超清图片、组图功能、水印控制，适合高质量商业图片生成

### 14.2 Banana 2 API

- **Base URL**: API 服务地址，如 `https://api.bananaprostudio.com`
- **API Key**: 用于身份验证的密钥
- **特点**: 支持多种比例和分辨率的图片生成，支持角色融图，适合创意图片生成

### 14.3 使用建议

1. 建议至少配置一个 API 以便正常使用
2. 点击"测试连接"可验证 API 是否可用
3. API Key 会本地加密存储，请放心使用
4. 如遇到 API 异常，可查看统计页面分析调用情况

### Q13: 测试连接显示失败怎么办？

A: 请检查：

1. Base URL 是否正确（注意 https:// 开头）
2. API Key 是否正确输入
3. 网络是否正常
4. API 服务是否可用（可访问 Base URL 确认）
