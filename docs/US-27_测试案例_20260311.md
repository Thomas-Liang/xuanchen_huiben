# US-27 测试案例（2026-03-11）

## 一、测试范围

覆盖一键项目导出包功能：

- 导出范围选择
- ZIP 打包
- 导出预览
- 索引文件生成

## 二、测试用例

| 用例ID | 用例名称          | 步骤                       | 预期结果                       |
| ------ | ----------------- | -------------------------- | ------------------------------ |
| T27.1  | 导出全部历史      | 不设置筛选条件，点击导出   | 导出所有历史记录               |
| T27.2  | 按时间范围导出    | 设置日期范围，点击导出     | 仅导出日期范围内的记录         |
| T27.3  | 按模型筛选导出    | 选择特定模型，点击导出     | 仅导出该模型的记录             |
| T27.4  | 按关键词搜索导出  | 输入提示词关键词，点击导出 | 仅导出包含关键词的记录         |
| T27.5  | 预览导出内容      | 点击导出项目包，查看预览   | 显示记录数量和详情列表         |
| T27.6  | 导出为ZIP         | 确认预览后选择保存位置     | 生成 .zip 文件                 |
| T27.7  | 导出包含图片      | 历史记录有图片的导出       | ZIP 中包含 assets/images/ 目录 |
| T27.8  | 索引文件-JSON     | 查看导出的 index.json      | 包含完整的记录数据             |
| T27.9  | 索引文件-Markdown | 查看导出的 README.md       | 包含可读的记录列表             |
| T27.10 | 空结果导出        | 筛选无结果时点击导出       | 提示"没有符合条件的记录"       |
| T27.11 | 取消导出          | 预览后点击取消             | 不生成文件                     |
| T27.12 | 导出进度          | 大量记录导出时             | 显示 loading 状态              |
