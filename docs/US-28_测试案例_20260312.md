# US-28 测试案例 - 桌面通知

> 日期: 2026-03-12

## 功能模块

V3-28: 桌面通知

## 前置条件

1. 应用已正确安装并运行
2. Windows 通知功能已开启

---

## 测试案例

### TC-28-01: 生成完成通知

**测试步骤**:

1. 打开应用
2. 输入提示词生成图片
3. 等待图片生成完成

**预期结果**:

- 系统发送通知 "图片生成完成"
- 通知内容显示成功生成的张数

**状态**: ⬜

---

### TC-28-02: 生成失败通知

**测试步骤**:

1. 打开应用
2. 输入提示词（使用会导致失败的参数）
3. 等待图片生成

**预期结果**:

- 系统发送通知 "图片生成失败"
- 通知内容显示错误原因

**状态**: ⬜

---

### TC-28-03: 通知开关

**测试步骤**:

1. 在设置中关闭通知功能
2. 生成图片

**预期结果**:

- 不发送系统通知

**状态**: ⬜

---

### TC-28-04: 通知权限请求

**测试步骤**:

1. 首次生成图片（系统未授权通知）
2. 观察是否弹出权限请求

**预期结果**:

- 应用请求通知权限
- 用户同意后发送通知

**状态**: ⬜

---

## 测试数据

| 案例     | 测试数据     | 预期结果     |
| -------- | ------------ | ------------ |
| TC-28-01 | 正常提示词   | 发送成功通知 |
| TC-28-02 | 无效 API Key | 发送失败通知 |
| TC-28-03 | 通知设置关闭 | 不发送通知   |

## 风险与备注

- Windows 通知中心可能被禁用
- 首次需要授权通知权限
