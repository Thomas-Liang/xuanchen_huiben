# US-25 开发记录（2026-03-10）

## 一、用户故事

作为用户，我希望更高效管理模板（分组、收藏、迁移），让模板长期可维护。

## 二、验收标准

- [x] 模板支持分组管理与分组筛选
- [x] 模板支持收藏与按"收藏优先"排序
- [x] 支持模板导出为 JSON 文件
- [x] 支持从 JSON 导入模板（含冲突处理策略）
- [x] 保留内置模板并支持与自定义模板共存

## 三、关键实现点

### 1) 数据模型扩展

在 `PromptTemplate` 结构体中新增字段：

- `group: String` - 分组（如：默认、内置、我的分组）
- `is_favorite: bool` - 是否收藏
- `is_builtin: bool` - 是否内置模板（受保护）

### 2) 后端 API 新增

- `update_prompt_template_favorite` - 切换收藏状态
- `update_prompt_template_group` - 更新分组
- `export_prompt_templates` - 导出选中的模板为 JSON
- `import_prompt_templates` - 导入 JSON，支持冲突策略（skip/overwrite/rename）

### 3) 内置模板保护

- 内置模板标记 `is_builtin = true`
- 编辑/删除操作检查内置标记，内置模板不可修改和删除
- 提供"复制"功能创建副本供用户修改

### 4) 前端界面增强

- 分组筛选下拉框
- 分类筛选下拉框（动态从模板中提取）
- 收藏按钮（星标图标）
- 收藏优先排序开关
- 搜索功能（按名称/内容）
- 导入/导出按钮
- 批量选择功能
- 模板卡片显示：内置标签、分组标签、收藏状态

## 四、涉及文件

- `src-tauri/src/storage/mod.rs` - 数据模型和存储逻辑
- `src-tauri/src/lib.rs` - Tauri 命令注册
- `src/api.ts` - 前端 API 接口
- `src/types/index.ts` - TypeScript 类型定义
- `src/components/templates/PromptTemplateModal.tsx` - 模板管理界面
