# US-22 开发记录（2026-03-09）

## 一、用户故事

作为用户，我希望可以管理生成任务队列（排队、暂停、继续、取消、重试），避免批量生图时失控。

## 二、实现范围（V1）

- 前端新增“任务队列中心”弹窗。
- 单图/批量入口由“全部生图”调整为“加入队列”。
- 支持任务状态流转：
  - `pending`
  - `running`
  - `paused`
  - `completed`
  - `failed`
  - `cancelled`
- 支持任务操作：
  - 暂停
  - 继续
  - 取消
  - 重试
  - 清理已结束任务
- 支持队列元数据本地持久化（应用重启后恢复）。

## 三、关键实现点

### 1) 队列数据结构

在 `src/App.tsx` 中新增 `GenerationQueueTask`，包含：

- 任务基础信息（id/name/mode/status/time）
- 任务载荷（segments/model/参数快照）
- 任务进度（current/total/sceneResults）

### 2) 队列执行器

- 新增 `executeQueueTask()` 负责顺序执行任务。
- 执行前检查取消/暂停标记，保证可控性。
- 当前版本采用顺序调度，优先保证暂停体验稳定。

### 3) 任务控制

- `handlePauseQueueTask()`
- `handleResumeQueueTask()`
- `handleCancelQueueTask()`
- `handleRetryQueueTask()`
- `handleClearFinishedQueue()`

### 4) 可测试性增强

在“生成设置”中新增“队列测试模式”：

- 可配置模拟延迟（毫秒）
- 可指定第 N 条模拟失败
- 测试模式下不调用真实生图 API，不写入历史

用于稳定复测暂停/继续/取消/重试流程。

### 5) 并发调度器 (2026-03-09 新增)

- 新增 `processBatch()` 函数实现并发执行
- 使用 `Promise.race` + `Set` 跟踪进行中的任务
- 支持配置并发数（1-5），在"生成设置"中配置
- 并发模式下保持暂停/取消功能正常：
  - 暂停：等待当前批次完成后停止，不启动新任务
  - 取消：立即停止新任务启动，已进行任务继续完成

## 四、当前限制（V1）

- 队列持久化当前为前端本地存储，后续可迁移到 Tauri 存储层。
