## 六、问题修复（2026-03-11）

### 问题描述

导出的 ZIP 包中只有 JSON 索引文件，没有实际的图片文件。

### 原因分析

1. 数据库中存储的图片是 base64 数据 URL（`data:image/png;base64,...`），而非文件路径或 HTTP URL
2. 原导出代码只处理了文件路径和 HTTP URL，对 base64 数据直接跳过

### 修复内容

1. **修改 `export_package.rs` 的 `collect_images_for_records` 函数**：
   - 检测 `data:` 开头的 base64 数据 URL
   - 解码 base64 数据并保存为 PNG 文件
   - 生成唯一文件名（使用记录 ID）

2. **修改 `image_generator.rs` 的图片保存逻辑**：
   - 添加详细错误日志以便调试
   - 修复 fallback 逻辑：当本地保存失败时使用原始 URL

- `src-tauri/src/commands/export_package.rs`
- `src-tauri/src/commands/image_generator.rs`
