## 备注

- Tailwind CSS v4 使用了新的配置方式，需要安装 `@tailwindcss/postcss` 包
- 使用 `@import "tailwindcss"` 替代旧的 `@tailwind base/components/utilities` 语法
- 创建了 `antd-compat.css` 处理 Ant Design 与 Tailwind 的样式兼容问题
