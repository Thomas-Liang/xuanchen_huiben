# US-26 开发记录（2026-03-11）

## 一、用户故事

作为用户，我希望系统自动辅助整理图库（标签建议、重复图识别），减少人工整理成本。

## 二、验收标准

- [x] 提供基于文件特征的重复图检测能力
- [x] 提供标签建议（可人工确认后写入）
- [x] 支持批量合并或删除重复项
- [x] 输出整理建议清单（候选、置信度、建议操作）
- [x] 所有自动化操作均支持预览与撤销

## 三、关键实现点

### 1) 图片特征提取

使用平均哈希（Average Hash）算法提取图片特征：

- 将图片缩放到 8x8 像素
- 转换为灰度图
- 计算像素平均值
- 生成 64 位哈希字符串

### 2) 重复图检测

相似度计算逻辑：

- 哈希相似度 >= 95% 直接判定为重复
- 哈希相似度 >= 85% + 尺寸相似 + 文件大小相似 = 重复
- 尺寸相似：宽高比在 0.8-1.25 之间
- 文件大小相似：大小比在 0.7-1.4 之间

### 3) 标签建议生成

基于以下规则推断标签：

- 图片类型 → 预设标签（如"人物"→"可爱/帅气/美丽"）
- 角色名称关键词 → 推断标签（如名称含"男"→"男性"）

### 4) 操作撤销机制

- 使用内存存储操作日志
- 支持撤销最近的操作
- 记录操作类型、目标、原值、新值、时间戳

### 5) 后端 API 新增

- `analyze_reference_library` - 分析图库，返回重复图和标签建议
- `execute_organization_action` - 执行整理操作（应用标签/删除重复）
- `undo_organization_action` - 撤销操作
- `get_organization_action_log` - 获取操作日志
- `delete_duplicate_images` - 批量删除重复图片

## 五、UI 交互流程

1. 打开参考图库
2. 点击"智能整理"按钮
3. 系统分析图库，显示：
   - 重复图片分组（显示相似度和代表图）
   - 标签建议列表
4. 用户可：
   - 选择重复项删除
   - 一键应用标签建议
   - 查看操作历史并撤销
