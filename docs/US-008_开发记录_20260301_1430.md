## 功能概述

实现批量提示词拆分功能，支持按分隔符或自动识别场景模式将一段提示词拆分成多个独立场景。

## 4. 故障排查与修复 (2026-03-01)

### 4.1 修复后端 Panic (500 错误)

**时间**: 2026-03-01 15:10  
**现象**: 调用 `/api/batch-split` 时后端直接崩溃并返回 Internal Server Error (500)。  
**原因**: Rust 原生 `regex` 库不支持正则表达式中的“先行断言” (look-around/look-ahead)，导致 `unwrap()` 时 Panic。  
**修复**: 重写 `parse_scene_pattern` 函数，改用 `find_iter` 匹配分隔标号，并手动计算偏移量进行内容截取。

### 4.2 智能自动识别增强

**时间**: 2026-03-01 15:20  
**功能**:
- 增强了 `auto_detect` 逻辑。当模式匹配失败时，会自动尝试按常见分隔符 (`|`, `\n`, `;`) 进行权重拆分。
- 优化了角色提取的健壮性。

### 4.3 API 层优化与错误反馈

**时间**: 2026-03-01 15:22  
**优化内容**:
- 统一了 API 错误响应格式，确保所有 500 或 400 错误都返回结构化的 JSON `{ "error": "msg" }`，方便前端提示。
- 简化了 `api_batch_split_prompt` 的实现，从手动读取 Body 字节流切换回 Axum 的 `Json` 提取器，提高代码可读性。

### 4.4 单元测试覆盖

**时间**: 2026-03-01 15:23  
**新增测试**:
- `test_batch_split_smart_auto_detect`: 验证 `|` 分隔符在自动模式下的识别。
- `test_batch_split_numeric_pattern`: 验证 `场景1:` 格式的精确截取。
- **结果**: 所有 6 项后端单元测试全部通过。
