## 一、用户故事

作为用户，我希望对比两次生成结果并一键复用参数，快速迭代出更优图像。

## 二、验收标准

- [x] 支持从历史中选择两条记录进行并排对比
- [x] 展示关键参数差异（模型、尺寸、质量、参考图等）
- [x] 支持"一键沿用参数重新生成"
- [x] 支持在复用前编辑参数再生成
- [x] 复用生成会写入历史并标记来源记录

## 三、关键实现点

### 1) 对比功能入口

在历史记录列表操作栏新增"对比"按钮，支持选择2条记录进行对比。

### 2) 对比视图Modal

创建 `compareItems` 状态管理选中的记录，实现并排展示：

- 记录基本信息（时间、提示词）
- 生成的图片
- 一键沿用 / 编辑后生成按钮

### 3) 参数差异计算

实现 `computeParamDiff()` 函数，对比两条记录的参数：

- 提取所有参数键（模型、尺寸、质量、水印等）
- 高亮差异项：记录1不同=红色，记录2不同=绿色
- 相同参数显示为"相同"

### 4) 来源记录标记

在 `GenerationHistory` 数据结构中新增 `source_history_id` 字段：

- 重新生成时自动记录来源历史记录ID
- 保存到后端存储
- 前端API和后端模型同步扩展

### 5) 任务队列集成

修改 `handleRegenerateHistory` 函数：

- 直接创建任务加入队列（而非填充表单）
- 传递 `sourceHistoryId` 到任务payload
- 生成完成后自动保存来源标记

### 6) 编辑表单优化

- Seedream 使用下拉选项（1K/2K/4K）替代数字输入
- 使用 `shouldUpdate` + `getFieldValue` 动态切换模型字段
- 加载时正确回显已保存的参数值
