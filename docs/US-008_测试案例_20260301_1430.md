## 功能概述

实现批量提示词拆分功能，支持按分隔符或自动识别场景模式将一段提示词拆分成多个独立场景。

本文档涵盖 US-008 批量提示词拆分功能的所有测试案例，包括：

- 自定义分隔符拆分
- 自动识别场景模式
- 角色提取验证

---

- **前端**: React + TypeScript + Ant Design
- **后端**: Rust + Tauri
- **测试工具**: 手动测试

## 测试用例

### TC-001: 使用竖线分隔符拆分

**前置条件**: 无

**测试步骤**:

1. 切换到"批量"模式
2. 在分隔符输入框中输入 `|`
3. 在提示词输入框中输入：`在森林里@小明 正在跑步 | 海边@女孩 正在散步`
4. 点击"拆分场景"按钮

**测试数据（试试看示例）**:

```
在森林里@小明 跑步 | 海边@女孩 散步 | 山上@英雄
```

**预期结果**:

- 拆分结果显示 2 个场景
- 场景1内容：`在森林里@小明 正在跑步`
- 场景2内容：`海边@女孩 正在散步`
- 场景1识别出角色：小明
- 场景2识别出角色：女孩

**测试结果**: ⬜ 待测试
