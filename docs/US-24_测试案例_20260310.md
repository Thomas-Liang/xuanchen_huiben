# US-24 测试案例（2026-03-10）

## 一、测试范围

覆盖结果对比与参数复用功能：

- 历史记录选择对比
- 并排对比视图展示
- 参数差异计算和高亮
- 一键沿用重新生成
- 编辑后重新生成
- 来源记录标记
