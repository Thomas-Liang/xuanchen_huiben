# US-09 开发记录 - 历史记录浏览与筛选增强

## 1. 任务概述
提取 US-09 的任务并完成相关功能，主要涉及生成历史记录的时间线浏览、多维度筛选（模型、日期、关键字）以及快速筛选功能。

## 2. 需求分析
### 2.1 核心任务 (US-09):
- **T9.1: 实现按日期分组展示** - 将历史记录按天分组，方便用户按时间线查看。
- **T9.2: 开发筛选组件** - 提供模型筛选（Seedream/Banana Pro）和日期范围筛选。
- **T9.3: 实现搜索功能** - 支持通过提示词关键字进行模糊搜索。
- **T9.4: 添加快捷筛选按钮** - 提供“今天”、“本周”、“本月”的快速切换。

## 3. 方案设计
### 3.1 后端增强:
- 修正 Rust 后端的日期格式，从非标准的 `%Y-%m-%d %H:%M:%S` 切换为标准的 RFC3339 格式，解决前端传递的 ISOString 无法被 Rust 正确解析的问题。
- 在 `storage::get_history` 中增加对旧日期格式的兼容处理，确保升级过程平滑。
- 补全 Axum HTTP API 的历史记录相关接口（/api/history/*），使后端功能在非 Tauri 环境下也具备完整性。

### 3.2 前端优化:
- **搜索防抖 (Debounce)**: 避免关键字输入时频繁触发 API 调用。
- **UI 布局优化**: 使用毛玻璃效果和更细腻的 Ant Design 样式，提升“高级感”。
- **状态同步**: 确保快速筛选按钮与日期选择器状态同步。

## 4. 实施过程
