### T8.4: 添加生成时自动保存逻辑

**文件位置**: `src/App.tsx`

在生成图片完成后自动保存到历史记录：

```typescript
// 保存到历史记录
if (result.success) {
  await addHistory({
    id: `gen_${Date.now()}`,
    prompt: ...,
    model: params.model,
    params: params,
    images: result.images,
    characters: parsedResult?.characters?.map(c => c.name) || [],
    status: result.success ? 'completed' : 'failed',
    created_at: new Date().toISOString(),
    updated_at: new Date().toISOString(),
  });
}
```
