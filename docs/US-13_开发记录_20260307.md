## 实现细节

### 1. 数据结构 (Rust)

在 `src-tauri/src/storage/mod.rs` 中新增 `PromptTemplate` 结构：

```rust
pub struct PromptTemplate {
    pub id: String,
    pub name: String,
    pub content: String,
    pub category: String,
    pub variables: Vec<String>,
    pub usage_count: u32,
    pub created_at: String,
    pub updated_at: String,
}
```

- 自动提取变量：模板内容中使用 `{变量名}` 格式定义变量
- 使用次数统计：每次使用模板时自动 +1

### 2. 后端 API

新增 6 个 Tauri 命令：

- `add_prompt_template` - 创建模板
- `get_all_prompt_templates` - 获取所有模板
- `get_prompt_template_by_id` - 获取单个模板
- `update_prompt_template` - 更新模板
- `delete_prompt_template` - 删除模板
- `increment_template_usage` - 增加使用次数

### 3. 前端组件

## 联调补充修复（2026-03-07 晚间）

本轮联调主要解决了模板功能在真实使用链路中的外围稳定性问题，确保“模板填充提示词 -> 生图 -> 保存 -> 历史复盘”闭环可用。

### 1) 生图接口稳定性（模板使用后同样受益）

**问题**:
- Banana Pro 在带参考图请求时出现 `500 invalid_request`、`400 Bad Request (nginx)`。

**修复** (`src-tauri/src/commands/image_generator.rs`):
- 限制参考图数量与单图 base64 体积，避免超大请求体。
- `api_key` URL 编码后拼接请求地址。
- 命中 `400/413` 或 JSON 截断错误时自动降级重试（无参考图）。

### 2) 生成结果保存体验修复

**问题**:
- 点击保存图片会弹浏览器窗口，影响桌面端体验。

**修复** (`src/api.ts`):
- Tauri 环境仅使用原生保存对话框与本地写文件命令。
- 移除会打开新窗口的兜底下载逻辑。

### 3) 模板生成后的历史复盘链路修复

**问题**:
- 生图成功后，历史记录可能无法加载（参数映射异常 + 旧数据库字段缺失）。

**修复**:
- `src/api.ts`：历史查询参数同时兼容 camelCase/snake_case。
- `src/components/history/HistoryList.tsx`：历史加载失败显示明确提示。
- `src-tauri/src/storage/mod.rs`：数据库结构增加 `#[serde(default)]`，兼容旧 `database.json`（如缺少 `prompt_templates`）。

### 4) 补充影响文件

1. `src-tauri/src/commands/image_generator.rs`
2. `src-tauri/src/storage/mod.rs`
3. `src-tauri/Cargo.toml`
4. `src/api.ts`
5. `src/components/history/HistoryList.tsx`

## 模板能力增强（2026-03-07 夜间补充）

### 1) 内置模板初始化

为“模板作用不明显、首次使用无引导”问题补充默认模板能力：

- 新装数据库默认注入 3 条内置模板
- 老版本数据库若模板为空，启动后自动补齐内置模板（兼容迁移）

内置模板内容：
- 儿童绘本场景模板
- 国风插画模板
- 电影感写实模板

### 2) 模板创建/更新入参修正

修复 `add_prompt_template` 创建时报 `missing field id`：

- 新增 `PromptTemplatePayload`（`name/content/category`）
- 创建时后端自动生成 `id/variables/created_at/updated_at`
- 更新时保留原记录元数据，仅更新可编辑字段并重算变量

### 3) 交互说明增强

在模板弹窗顶部增加说明文案，提示“可直接使用内置模板并替换变量”。

### 4) 左侧导航入口修复

修复“左侧导航点击模板无反应”问题：

- 原因：`Toolbar` 触发 `onNavigate('templates')` 后，`App.tsx` 未处理该分支
- 修复：`handleNavigate` 中增加 `templates` 分支，点击左侧模板图标直接打开模板弹窗
