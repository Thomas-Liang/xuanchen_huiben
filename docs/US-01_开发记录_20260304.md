## 概述

US-01 旨在为项目引入 Tailwind CSS 框架，并配置主题系统为后续的 UI 优化和暗色主题支持奠定基础。

---

## 完成的工作

### 1. 安装 Tailwind CSS 依赖

**执行命令**:

```bash
npm install -D tailwindcss postcss autoprefixer
npm install -D @tailwindcss/postcss
```

**说明**: Tailwind CSS v4 需要使用 `@tailwindcss/postcss` 包作为 PostCSS 插件。

---

### 2. 创建配置文件

#### tailwind.config.js

```javascript
/** @type {import('tailwindcss').Config} */
export default {
  content: ['./index.html', './src/**/*.{js,ts,jsx,tsx}'],
  darkMode: 'class',
  theme: {
    extend: {
      colors: {
        primary: { DEFAULT: '#6366f1', light: '#818cf8', dark: '#4f46e5' },
        secondary: { DEFAULT: '#8b5cf6', light: '#a78bfa', dark: '#7c3aed' },
      },
      // ...
    },
  },
  plugins: [],
};
```

#### postcss.config.js

```javascript
export default {
  plugins: {
    '@tailwindcss/postcss': {},
    autoprefixer: {},
  },
};
```

---

### 3. 创建全局样式文件

#### src/index.css

- 使用 Tailwind v4 新语法 `@import "tailwindcss"`
- 定义 CSS 变量支持亮色/暗色主题
- 创建 `.glass-card` 毛玻璃效果类
- 创建 `.btn-primary` 按钮样式
- 添加动画工具类
- 添加骨架屏效果

#### src/antd-compat.css

处理 Ant Design 组件与 Tailwind 的样式兼容，包括：

- 按钮、输入框、卡片
- 开关、标签、模态框
- 下拉菜单、Tabs、Collapse
- 列表、空状态、加载动画等

---

### 4. 更新入口文件

#### src/main.tsx

```typescript
import './index.css';
import './antd-compat.css';
```

## 遇到的问题及解决方案

### 问题1: Tailwind CSS v4 配置方式变化

**现象**: 运行时报错 `The PostCSS plugin has moved to a separate package`

**原因**: Tailwind CSS v4 改变了 PostCSS 插件的使用方式

**解决**: 安装 `@tailwindcss/postcss` 并更新配置
