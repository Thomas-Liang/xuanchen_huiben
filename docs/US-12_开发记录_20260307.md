## 联调补充修复（2026-03-07 晚间）

### 1) 生图 API 稳定性修复

**问题现象**:
- Banana Pro 调用出现 `500 invalid_request`、`unexpected end of JSON input`
- 随后出现网关 `400 Bad Request (nginx)`

**根因分析**:
- 请求体在携带多张/超大 base64 参考图时过大，网关层可能截断或拒绝解析
- `api_key` 未做 URL 编码，特殊字符可能触发网关 400

**修复内容** (`src-tauri/src/commands/image_generator.rs`):
- 限制 Banana Pro 参考图数量与单图 base64 大小（超限跳过）
- `api_key` 改为 URL 编码后拼接到请求地址
- 命中 `400/413` 或 `unexpected end of JSON input` 时，自动降级重试一次“无参考图”请求

### 2) 保存图片行为修复（不再弹浏览器窗口）

**问题现象**:
- 点击“保存图片”会弹出浏览器窗口

**修复内容** (`src/api.ts`):
- Tauri 环境只走原生保存对话框 + `save_image_to_file`
- 移除会触发新窗口的兜底逻辑（`target="_blank"`）
- Web fallback 失败时直接抛错提示，不再打开新窗口

### 3) 历史记录链路修复

**问题现象**:
