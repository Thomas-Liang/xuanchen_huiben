## 二、V3-32: 一键分享

### 2.1 需求分析

用户希望能够快速分享生成的图片到外部，支持以下场景：

- 生成分享链接，接收者无需登录即可查看
- 支持设置链接有效期（1天/7天/永久）
- 支持设置访问密码
- 支持生成二维码方便手机扫码
- 支持复制链接到剪贴板
- 支持直接分享到社交媒体

### 2.2 技术方案

**分享链接生成流程**：

```
┌─────────────────────────────────────────────────────────────┐
│                    一键分享流程                               │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  1. 用户点击"分享"按钮                                       │
│            ↓                                                 │
│  2. 弹窗选择分享方式：                                       │
│     ├── 复制链接                                             │
│     ├── 生成二维码                                           │
│     └── 社交媒体分享                                         │
│            ↓                                                 │
│  3. 设置分享选项：                                           │
│     ├── 有效期：[1天/7天/永久]                               │
│     └── 访问密码：[可选]                                     │
│            ↓                                                 │
│  4. 生成本地分享文件 (JSON + 图片打包) 或                    │
│     上传到临时存储服务（可选）                                │
│            ↓                                                 │
│  5. 返回分享链接/二维码                                      │
│                                                              │
└─────────────────────────────────────────────────────────────┘
```

**本地分享模式**（无需服务器）：

- 将图片和元数据打包为单个 HTML 文件
- 接收者打开 HTML 文件即可在浏览器中查看
- 无需网络访问，完全离线可用

**分享数据格式**：

```json
{
  "version": "1.0",
  "type": "image_share",
  "created_at": "2026-03-12T10:30:00Z",
  "expires_at": "2026-03-19T10:30:00Z",
  "password_protected": false,
  "metadata": {
    "prompt": "阳光下的少女",
    "model": "seedream",
    "params": {
      "width": 1024,
      "height": 1024,
      "quality": "high"
    }
  },
  "images": [
    {
      "id": "img_001",
      "data": "base64encodedimage..."
    }
  ]
}
```

## 三、V3-33: API 开放

### 3.1 需求分析

作为开发者，我希望通过 API 调用应用功能，实现自动化工作流：

- RESTful API 接口规范
- Token/API Key 认证
- 频率限制
- 完整 API 文档

### 3.2 API 端点规划

| 方法   | 端点                     | 描述         | 认证    |
| ------ | ------------------------ | ------------ | ------- |
| POST   | /api/v1/generate         | 创建生成任务 | API Key |
| GET    | /api/v1/tasks/:id        | 获取任务状态 | API Key |
| POST   | /api/v1/tasks/:id/cancel | 取消任务     | API Key |
| GET    | /api/v1/history          | 获取历史记录 | API Key |
| GET    | /api/v1/templates        | 获取模板列表 | API Key |
| POST   | /api/webhook/register    | 注册 Webhook | API Key |
| DELETE | /api/v1/webhooks/:id     | 删除 Webhook | API Key |
| GET    | /api/v1/health           | 健康检查     | 无      |

### 3.3 接口详细设计

#### 3.3.1 创建生成任务

**请求**：

```http
POST /api/v1/generate
Authorization: Bearer <api_key>
Content-Type: application/json

{
  "prompt": "阳光下的少女",
  "model": "seedream",
  "character_bindings": [
    {
      "character_name": "小明",
      "reference_image_path": "path/to/image.jpg",
      "image_type": "人物"
    }
  ],
  "width": 1024,
  "height": 1024,
  "count": 1,
  "quality": "high",
  "webhook_url": "https://your-server.com/webhook"
}
```

**响应**：

```json
{
  "task_id": "task_abc123",
  "status": "pending",
  "created_at": "2026-03-12T10:30:00Z",
  "estimated_time": 30
}
```

#### 3.3.2 获取任务状态

**请求**：

```http
GET /api/v1/tasks/task_abc123
Authorization: Bearer <api_key>
```

**响应**：

```json
{
  "task_id": "task_abc123",
  "status": "completed",
  "progress": 100,
  "created_at": "2026-03-12T10:30:00Z",
  "completed_at": "2026-03-12T10:30:30Z",
  "result": {
    "images": [
      {
        "id": "img_001",
        "url": "https://...",
        "width": 1024,
        "height": 1024
      }
    ]
  }
}
```

### 3.4 认证与限流

**认证方式**：

- API Key 放在 Header: `Authorization: Bearer <api_key>`
- 支持在应用设置中生成/管理 API Key

**限流策略**：

| 套餐 | 频率限制     |
| ---- | ------------ |
| 免费 | 10 请求/分钟 |
| 付费 | 60 请求/分钟 |

**错误码**：

| 状态码 | 说明           |
| ------ | -------------- |
| 400    | 请求参数错误   |
| 401    | API Key 无效   |
| 403    | 超出频率限制   |
| 404    | 任务不存在     |
| 500    | 服务器内部错误 |

## 四、V3-31: 团队空间

### 4.1 需求分析

作为团队负责人/成员，我希望与团队共享参考图和模板：

- 创建/加入团队
- 团队内共享参考图库
- 团队内共享模板
- 团队成员权限管理
- 团队使用统计

```typescript

interface Team {
  id: string;
  name: string;
  owner_id: string;
  created_at: string;
  invite_code: string;

// 团队成员
interface TeamMember {
  id: string;
  team_id: string;
  user_id: string;
  role: 'owner' | 'admin' | 'member';
  joined_at: string;

// 共享参考图
interface SharedReference {
  id: string;
  team_id: string;
  owner_id: string;
  character_name: string;
  image_path: string;
  image_type: string;

  shared_at: string;

// 共享模板
interface SharedTemplate {
  id: string;
  team_id: string;
  owner_id: string;
  template_id: string;

}
```

## 六、技术注意事项

1. **安全性**
   - API Key 使用 AES 加密存储
   - 分享链接添加签名验证
   - 团队权限严格控制

2. **性能**
   - 团队图片使用缩略图列表
   - 大文件采用分片上传
   - API 限流使用 Redis（如果部署）

3. **兼容性**
   - API 保持版本化（v1）
   - 重大变更提前公告
   - 提供迁移文档
