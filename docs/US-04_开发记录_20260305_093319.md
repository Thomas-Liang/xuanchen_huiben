## 技术细节

### Tailwind CSS配置

项目已配置Tailwind CSS v4，使用`@import 'tailwindcss'`导入，并定义了自定义主题变量：

```css
@theme {
  --color-primary: #6366f1;
  --color-primary-light: #818cf8;
  --color-primary-dark: #4f46e5;
  --color-secondary: #8b5cf6;
}
```

### 暗色模式支持

所有组件都支持暗色模式，使用`dark:`前缀的Tailwind类：

```tsx
<div className="bg-gray-50 dark:bg-slate-700 hover:bg-gray-100 dark:hover:bg-slate-600">
```

### 渐变按钮样式

使用Tailwind渐变类实现品牌效果：

```tsx
className = 'bg-gradient-to-r from-indigo-500 to-violet-500 border-none';
```
