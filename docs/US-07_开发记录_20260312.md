## 技术细节

### 回调 Payload 格式

```json
{
  "event": "generation.completed",
  "timestamp": "2026-03-12T10:30:00Z",
  "data": {
    "task_id": "gen_1234567890",
    "status": "success",
    "images": ["data:image/png;base64,..."],
    "prompt": "生成的提示词",
    "model": "seedream"
  }
}
```

### 签名验证

- 使用 SHA256 生成签名
- 签名放在 `X-Webhook-Signature` 请求头
- 签名 = SHA256(payload + secret)

### 重试机制

- 默认重试 3 次
- 指数退避：1s, 2s, 4s...
