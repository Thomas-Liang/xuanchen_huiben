### T5.2: 实现页面切换过渡动画

**组件**: `PageTransition`

```typescript
export function PageTransition({ children, className }: PageTransitionProps) {
  return (
    <AnimatePresence mode="wait">
      <motion.div
        initial="initial"
        animate="animate"
        exit="exit"
        variants={pageVariants}
        className={className}
      >
        {children}
      </motion.div>
    </AnimatePresence>
  );
}
```

**使用方式**:

```tsx
import { PageTransition } from './theme/animations';

<PageTransition>
  <YourComponent />
</PageTransition>;
```

## 技术细节

### Framer Motion 配置

- 使用 `AnimatePresence` 实现组件进出动画
- 使用 `mode="wait"` 确保页面切换动画完整播放
- 使用自定义贝塞尔曲线 `[0.04, 0.62, 0.23, 0.98]` 实现平滑过渡

### 暗色模式支持

所有动画组件支持暗色模式，使用 Tailwind 的 `dark:` 前缀类名。

### 性能优化

- 使用 `will-change` 提示浏览器优化
- 动画使用 `transform` 和 `opacity` 属性，确保 60fps 流畅度
- 骨架屏使用 CSS 渐变动画，减少 JavaScript 负担
