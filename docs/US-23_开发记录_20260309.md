# US-23 开发记录

**功能**: 历史记录高级检索与保存筛选  
**故事点**: 5

## 功能概述

为历史记录增加更多筛选条件，并支持保存常用筛选方案。

## 验收标准

- [x] 支持按角色、标签、模型、时间范围筛选
- [ ] 支持按关键参数区间筛选（如分辨率/质量）
- [x] 支持保存筛选方案并命名
- [x] 支持加载和删除已保存筛选方案
- [x] 导出功能与当前筛选条件保持一致

## 实现细节

### 1) 数据模型扩展

在 `storage/mod.rs` 新增：

- `HistoryFilter` 新增 `character` 字段
- `SavedFilter` 结构：
  - `id`
  - `name`
  - `model`
  - `prompt_keyword`
  - `start_date`
  - `end_date`
  - `character`
  - `created_at`
- `Database` 新增 `saved_filters` 字段

### 2) 后端 CRUD

新增存储函数：

- `add_saved_filter()` - 保存筛选方案
- `get_saved_filters()` - 获取筛选方案列表
- `delete_saved_filter()` - 删除筛选方案

### 3) Tauri 命令

在 `lib.rs` 新增：

- `add_saved_filter`
- `get_saved_filters`
- `delete_saved_filter`

### 4) 前端 API

在 `api.ts` 新增：

- `addSavedFilter()`
- `getSavedFilters()`
- `deleteSavedFilter()`

### 5) 前端 UI

在 `HistoryList.tsx` 新增：

- 角色筛选输入框
- 筛选方案下拉选择（加载已保存方案）
- 保存筛选方案按钮和弹窗
