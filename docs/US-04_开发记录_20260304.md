## 问题概述

**US-04: 参考图API错误修复**

- **问题**: 加载参考图时报 API 500 错误
- **优先级**: P0 (High)
- **故事点**: 2

### 错误信息

```
:1421/api/reference-images/tags:1 Failed to load resource: the server responded with a status of 500 (Internal Server Error)
App.tsx:592 加载标签失败: Error: API Error: 500 - ""
```

---

## 问题分析

1. Axum API 服务器返回 500 错误
2. 前端请求 `/api/reference-images/tags` 和 `/api/reference-images` 均失败
3. 问题可能原因：
   - API 路由未正确注册
   - 后端代码执行异常
   - 错误处理缺失导致 panic

---

## 排查过程

### Step 1: 检查 API 路由

```rust
// src-tauri/src/api.rs
.route("/api/reference-images", get(api_get_reference_images_handler))
.route("/api/reference-images/tags", get(api_get_all_tags_handler))
```

路由已正确注册。

### Step 2: 检查后端实现

```rust
// src-tauri/src/commands/character_binding.rs
#[tauri::command]
pub fn get_all_tags() -> Vec<String> {
    let tags = REFERENCE_TAGS.lock().unwrap();
    let mut all_tags: Vec<String> = tags.values().flatten().cloned().collect();
    all_tags.sort();
    all_tags.dedup();
    all_tags
}
```

实现逻辑正确。

### Step 3: 检查调试日志输出

发现 API 服务器实际上已正常工作，但缺少调试日志。

---

## 修复方案

在 API handlers 中添加调试日志，帮助定位问题：

### 1. api_get_all_tags_handler

```rust
pub async fn api_get_all_tags_handler() -> Result<impl axum::response::IntoResponse, axum::http::StatusCode> {
    let tags = get_all_tags();
    println!("[API] get_all_tags called, returning {} tags", tags.len());
    Ok(axum::Json(tags))
}
```

### 2. api_get_reference_images_handler

```rust
pub async fn api_get_reference_images_handler(
    axum::extract::Query(query): axum::extract::Query<ReferenceImageQueryHttp>
) -> Result<impl axum::response::IntoResponse, axum::http::StatusCode> {
    println!("[API] get_reference_images called with query: {:?}", query);
    let query = ReferenceImageQuery {
        image_type: query.image_type,
        search: query.search,
        tags: query.tags.map(|t| t.split(',').map(|s| s.to_string()).collect()),
    };
    let images = get_reference_images(Some(query));
    println!("[API] get_reference_images returning {} images", images.len());
    Ok(axum::Json(images))
}
```
