# 🎨 泫晨懿然·灵犀绘梦

> 基于 Tauri + React 开发的灵犀绘梦桌面应用，支持 Seedream 和 Banana 2 两大 AI 绘画模型

![Tauri](https://img.shields.io/badge/Tauri-2.x-blue)
![React](https://img.shields.io/badge/React-19-blue)
![TypeScript](https://img.shields.io/badge/TypeScript-5.x-blue)
![License](https://img.shields.io/badge/License-MIT-green)

## ✨ 功能特性

### 🌓 主题切换

- 支持亮色主题和暗色主题
- 支持跟随系统主题自动切换
- 主题设置自动持久化保存
- 所有 Ant Design 组件完整适配深色模式

### 🔤 智能提示词解析

- 自动识别 `@角色名` 格式，提取角色信息
- 文本内容智能分段：场景、动作、人物、背景、时间、天气、风格
- 支持中英文混合输入

### 👤 角色绑定系统

- 上传参考图片绑定角色
- 支持人物/人脸/全身/场景四种参考图类型
- 本地路径和 Base64 图片双支持
- 角色绑定信息持久化存储
- **标签管理** - 可为参考图添加自定义标签，便于分类检索
- **参考图文件夹管理** - 支持树形文件夹、移动归档、上传时指定目录
- **重名校验** - 创建/重命名文件夹时同级重名会提示错误
- **图片点击预览** - 卡片图可点击放大查看完整大图
- **批量操作** - 支持多选模式下的批量移动、批量删除、批量添加标签
- **提示词模板** - 支持创建、使用提示词模板，变量替换，使用次数统计
- **提示词历史** - 自动保存常用提示词，支持下拉复用、去重排序、快速删除/清空
- **首页今日概览看板** - 首页单排展示日期时间、生成总数、成功率、失败数与最近失败信息
- **生成任务队列中心（US-22 V1）** - 支持加入队列、暂停/继续、取消、重试、清理已结束任务
- **历史记录导出** - 支持按当前筛选条件导出 JSON/Markdown（用于复盘与汇报）

### 🖼️ AI 图片生成

- **Seedream 4.5** - 支持 1K/2K/4K 超清图片、组图功能、水印控制
- **Banana 2** - 支持多种比例和分辨率的图片生成
- 实时进度显示
- 角色融图支持（通过参考图路径）
- **稳定性增强** - 网关异常时自动降级重试（无参考图），并在界面给出明确提示

### 📦 批量处理功能

- **批量提示词拆分** - 支持自定义分隔符（`|`、`;;`、`---`、换行、TAB等）或自动识别场景模式
- **批量角色绑定** - 每个场景可单独绑定角色参考图
- **全局绑定模式** - 所有场景共享角色绑定，一次绑定即可在所有场景中使用
- **并发生成** - 可配置 1-5 张图片同时生成
- **顺序生成** - 支持顺序生成模式，失败时可选择继续或停止
- **生成参数弹框** - 批量生成时可快速调整模型和参数

### 🔄 单图/批量模式切换

- **模式切换开关** - 顶部轻松切换单图/批量模式
- **解析结果折叠面板** - 单图模式下解析结果以折叠面板形式展示，包含原始提示词、角色、内容分段
- **全部生图功能** - 单图模式下也可批量生成所有分段图片
- **状态自动清除** - 切换模式时自动清除之前的结果数据

### ⚙️ 配置管理

- API Key 和 Base URL 灵活配置
- 生成参数预设保存
- 测试连接功能

## 🚀 快速开始

### 环境要求

- Node.js 18+
- Rust 1.70+
- Windows 10/11

### 安装

```bash
# 安装前端依赖
npm install
```

### 开发

```bash
# 方式一：使用启动脚本（推荐）
powershell -ExecutionPolicy Bypass -File start_dev.ps1

# 方式二：分别启动
# 终端1 - 启动前端
npm run dev

# 终端2 - 启动 Tauri 后端
cd src-tauri && cargo run
```

### 构建

```bash
# 构建桌面应用
npm run tauri build
```

## 📖 使用指南

### 1. 主题切换

点击界面右上角的 **主题切换** 按钮（太阳/月亮图标）：

- **亮色主题** - 浅色背景，适合白天使用
- **暗色主题** - 深色背景，减少眼睛疲劳
- **跟随系统** - 自动跟随操作系统的主题设置

主题设置会自动保存，下次打开应用时保持上次的选择。

### 2. 配置 API

点击界面右上角 **API配置** 按钮，配置以下信息：

- **Seedream API**
  - Base URL: `https://eggfans.com`
  - API Key: 你的密钥

- **Banana 2 API**
  - Base URL: `https://api.bananaprostudio.com`
  - API Key: 你的密钥

### 2. 输入提示词

在输入框中描述你的画面，使用 `@角色名` 绑定参考图：

```
在阳光明媚的森林里@小明 正在愉快地跑步
```

### 2.1 提示词历史（自动保存）

- 点击 **开始解析** 或 **拆分场景** 后，当前提示词会自动保存到历史
- 输入框上方可使用 **提示词历史下拉**，一键回填历史提示词
- 支持关键词搜索历史项
- 提供 **删首条**、**清空** 操作
- 输入框为空时，按 `Enter` 可快速回填最近一条提示词

### 2.2 首页今日概览看板

- 首页顶部提供“今日概览”看板，展示 `日期/时间`、`生成总数`、`成功率`、`失败数`、`最近失败`
- 看板采用单排卡片布局，避免遮挡主编辑区（当前版本不显示底部进度条）
- 最近失败内容过长时会自动省略，悬浮可查看完整信息
- “输入提示词”标题右侧显示 `（当前长度 / 最大长度）`，并带颜色提示与 Tooltip

### 3. 解析提示词

点击 **开始解析**，系统会：

- 提取角色信息
- 分隔文本内容
- 显示分段类型标签

### 4. 绑定参考图

点击角色旁的 **绑定参考图** 按钮：

- 上传参考图片
- 选择图片类型（人物/人脸/全身/场景）
- 确认绑定

### 5. 生成图片

选择模型和参数，点击 **开始生成**：

- Seedream: 支持尺寸、图片质量、组图、格式、水印设置
- Banana 2: 支持比例、分辨率设置
- 当参考图请求体过大或被网关拒绝时，系统会自动尝试降级重试并显示提示信息

### 5.1 参考图管理（文件夹）

在主界面打开 **参考图管理** 后，可进行以下操作：

- 左侧树节点支持 **全部图片 / 未分类(根目录) / 自定义文件夹**
- 点击文件夹右侧按钮可 **新建子文件夹 / 重命名 / 删除**
- 在图片卡片点击 **移动** 可转移到目标文件夹
- 点击 **上传图片** 可在弹窗中选择“保存至文件夹”
- 创建或重命名与同级目录重名时会直接报错
- 点击图片封面可进入大图预览

### 6. 批量处理（可选）

启用 **批量模式** 可一次性生成多张图片：

- **模式切换**: 点击"单图/批量"开关切换模式
- **拆分场景**: 输入包含多个场景的提示词，使用 `|` 分隔或自动识别场景模式
- **角色绑定**: 每个场景可单独绑定角色参考图
- **全局绑定**: 也可切换到全局绑定模式，一次绑定所有场景共享
- **设置**: 点击"设置"按钮可调整模型和参数
- **并发生成**: 可配置 1-5 张图片同时生成
- **加入队列**: 点击"加入队列"后由任务队列按顺序执行，支持暂停/继续/取消/重试

批量提示词示例：

```
场景1: 阳光明媚的公园里@小明 在跑步|场景2: 夜晚的街道@女孩 在行走|场景3: 海边的日落@英雄 站在礁石上
```

### 7. 单图模式生成（可选）

单图模式下也可使用批量生成功能：

- 输入提示词并解析后，显示解析结果折叠面板
- 点击"生成设置"可调整生成参数
- 点击"加入队列"可提交当前分段到任务队列执行

### 7.1 任务队列中心（US-22 V1）

- 入口：解析结果区域的 `任务队列` 按钮
- 状态：`pending / running / paused / completed / failed / cancelled`
- 操作：`暂停 / 继续 / 取消 / 重试 / 清理已结束`
- 测试模式：可在“生成设置”中开启，不调用真实 API，用于稳定复现队列流程
- 当前版本说明：暂停/取消为“分段级生效”（当前请求结束后阻止下一条）

### 8. 历史记录导出

在“生成历史记录”弹窗底部左侧可直接导出：

- `导出JSON`：结构化历史数据，便于二次处理
- `导出MD`：面向周报/复盘的可读文本

导出范围为“当前筛选条件下的全部历史记录”（非仅当前页）。

## 🔧 配置说明

### 生成参数

| 参数   | 说明        | 可选值                          |
| ------ | ----------- | ------------------------------- |
| 模型   | AI 模型选择 | seedream, banana_pro            |
| 尺寸   | 图片分辨率  | 1024x1024, 2048x2048, 4096x4096 |
| 比例   | 图片比例    | 1:1, 16:9, 9:16, 4:3, 3:4       |
| 分辨率 | 分辨率      | 1K, 2K, 4K                      |
| 组图   | 连图功能    | auto, disabled                  |
| 格式   | 返回格式    | url, b64_json                   |
| 水印   | 水印开关    | true, false                     |
| 数量   | 生成数量    | 1, 2, 4                         |
| 质量   | 图片质量    | standard, high, ultra           |
| 并发   | 并发数      | 1, 2, 3, 4, 5                   |

### 存储路径

- 配置文件: `%APPDATA%/xuanchen-huiben/`
- 参考图片: `%APPDATA%/xuanchen-huiben/reference_images/`
